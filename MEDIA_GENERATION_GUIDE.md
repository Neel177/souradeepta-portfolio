# Procedural world and optional media guide

The portfolio now renders its miniature world procedurally with one shared Three.js scene. It needs no downloaded models or videos to work. These optional stills and loops can later replace or enrich the matching procedural districts through `CinematicVideo`; keep the current scene as the fallback whenever an asset is missing or unavailable.

Use H.264 MP4, muted audio, 24 fps, 16:9, and a compressed poster image for each loop. Keep visual overlays decorative. For CGC, only the supplied live product or real screenshots should show actual interface data; generated UI must not imply real metrics, students, fees, or functionality.

Soft late-morning sun, gentle sky fill, delicate atmospheric depth, warm white highlights, sky blue, sage, muted coral and lavender accents. Stylized physical materials, clean silhouettes, refined miniature craft, believable scale. No recognizable real city, landmark, brand, text, logo, traffic jam, photorealistic people, cyberpunk neon, or toy-like plastic gloss.

**Video prompt:** Animate the still for 7 seconds as a calm seamless loop. Begin with a high wide view; drift forward and down by about 3 percent, while a single tiny car moves slowly along its existing road and tree crowns sway slightly. Clouds move almost imperceptibly. Keep every building, road, tree, sign and color in the same shape and location; preserve the empty left-side typography area. No cuts, new objects, fast motion, camera shake, text changes, or flicker. Match the first and last frames for looping.

**Delivery:** 16:9, 7 seconds, loopable, normal background, no alpha.

## Integration notes

- `CinematicVideo` accepts an optional `src`, `poster`, `className`, fallback children, and a touch fallback choice. Add a source only after its file exists in `public/media/`.
- It begins loading inside a 320 px viewport margin, pauses when it leaves that margin, and does not autoplay on touch or reduced-motion devices. The procedural 3D world and CSS city remain the fallback.
- Keep native scroll, section text, navigation and project details in HTML. Treat the 3D/video as a storytelling layer rather than the sole carrier of information.
- The one WebGL scene uses shared/instanced city geometry, capped pixel ratio and particles, no shadow maps, and one renderer. Replace assets selectively; do not create a separate renderer for each section.
